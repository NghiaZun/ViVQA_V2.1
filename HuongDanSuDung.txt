================================================================================
HƯỚNG DẪN SỬ DỤNG
Đề tài: ViGCT-VQA — Visual Question Answering tiếng Việt trên bộ dữ liệu ViVQA
================================================================================

Tài liệu này hướng dẫn cách biên dịch và chạy chương trình.

Chương trình viết bằng Python nên KHÔNG cần bước biên dịch riêng — Python là
ngôn ngữ thông dịch, mã nguồn chạy trực tiếp bằng lệnh "python". Trước khi chạy,
hãy hoàn tất cài đặt trong HuongDanCaiDat.txt và kích hoạt môi trường ảo:

    source .venv/bin/activate          # Linux/macOS

Mọi lệnh bên dưới chạy từ thư mục chứa "src/". Các script trong src/ import lẫn
nhau theo dạng module phẳng, nên hãy chạy chúng từ bên trong "src/" hoặc thêm
tiền tố "src/" như minh hoạ.

--------------------------------------------------------------------------------
1. CHUẨN BỊ DỮ LIỆU (KHÔNG kèm trong gói nộp)
--------------------------------------------------------------------------------
Bộ dữ liệu ViVQA là công khai — tải từ nguồn gốc rồi tạo split cục bộ.

File CSV cần các cột: question, answer, filename (tên file ảnh).
Ảnh để phẳng trong MỘT thư mục. Ví dụ nội dung CSV:

    question,answer,filename
    Đây là con gì?,con mèo,img_001.jpg
    Có bao nhiêu người?,3,img_002.jpg

Tạo tập validation và answer weights:

    python src/create_val_split.py \
        --input_csv train.csv --train_out train_split.csv --val_out val_split.csv \
        --val_ratio 0.1 --seed 42

    python src/compute_answer_weights.py \
        --train_csv train_split.csv --output answer_weights.json


--------------------------------------------------------------------------------
2. HUẤN LUYỆN MÔ HÌNH
--------------------------------------------------------------------------------
Lệnh huấn luyện cấu hình tốt nhất (tái hiện kết quả trong luận văn, seed=42):

    python src/train.py \
      --train_csv train_split.csv \
      --val_csv val_split.csv \
      --image_dir /duong/dan/toi/thu/muc/anh \
      --vision_model google/siglip-base-patch16-224 \
      --bartpho_model vinai/bartpho-syllable \
      --fusion_type text2vision --num_fusion_layers 2 \
      --use_text_lora --text_lora_r 16 --text_lora_alpha 32 \
      --use_vision_gate --vision_gate_init 1.0 --vision_gate_min_alpha 0.0 \
      --use_type_loss --type_loss_weight 0.2 \
      --use_contrastive --contrastive_lambda 0.05 \
      --use_siglip_pooler \
      --use_cdw_ce --cdw_lambda 0.1 \
      --answer_weights answer_weights.json \
      --pk_sampling --pk_p 4 --pk_k 3 \
      --epochs 40 --lr 7e-5 --weight_decay 0.01 --label_smoothing 0.1 \
      --scheduler cosine --warmup_epochs 3 \
      --early_stopping --early_stopping_patience 15 --early_stopping_metric em \
      --batch_size 12 --vision_dropout_rate 0.10 --num_workers 4 --seed 42 \
      --output_dir checkpoints_run/

- Tiếp tục từ checkpoint:  thêm  --resume checkpoints_run/last_model.pt
- Xem toàn bộ tham số:     python src/train.py --help
- Kết quả (best_model.pt, last_model.pt, đường cong huấn luyện, metrics) được
  ghi vào thư mục --output_dir.


--------------------------------------------------------------------------------
3. ĐÁNH GIÁ MÔ HÌNH
--------------------------------------------------------------------------------
    python src/eval.py \
      --checkpoint checkpoints_run/best_model.pt \
      --csv_path test.csv \
      --image_folder /duong/dan/toi/thu/muc/anh \
      --output_csv result.csv \
      --num_beams 3 --repetition_penalty 1.3 --max_length 10 \
      --use_synonyms --use_constrained \
      --train_csv_for_trie train_split.csv

In ra EM / F1 / ROUGE trên màn hình và ghi dự đoán từng mẫu vào result.csv.


--------------------------------------------------------------------------------
4. CHẠY PIPELINE FINE-TUNE TỰ ĐỘNG (tuỳ chọn)
--------------------------------------------------------------------------------
Pipeline lặp: eval -> phân tích lỗi -> sinh ảnh augmented (FLUX.1-dev) ->
merge dataset -> fine-tune. Cấu hình đọc từ src/config.py (chỉnh biến CFG
trước khi chạy).

    python src/main.py

Chi tiết từng bước, tham số config và sơ đồ luồng: xem src/PIPELINE.md.


--------------------------------------------------------------------------------
5. TRỰC QUAN HOÁ (tuỳ chọn)
--------------------------------------------------------------------------------
    python src/visualize_predictions.py     # xem dự đoán trên ảnh
    python src/visualize_tcvg_heatmap.py     # heatmap TCVG
    python src/visualize_alpha_chart.py      # biểu đồ vision-gate alpha

(Thêm --help sau mỗi lệnh để xem tham số cụ thể.)
